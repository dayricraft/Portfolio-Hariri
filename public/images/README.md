# Panduan Struktur Folder Gambar (Images Guide)

Folder ini berisi seluruh aset gambar yang digunakan pada portofolio Anda. Folder sudah dikelompokkan dengan rapi agar mudah dikelola (menambah, mengganti, atau menghapus foto).

---

## 📁 1. `images/projects/` (Proyek / Works)
Folder untuk tangkapan layar (screenshot) dari proyek yang tampil di bagian **Works** dan halaman arsip proyek.
- `agriflow.png` : Proyek 01 - AI Food Supply Chain Intelligence (Agriflow)
- `matverify.png` : Proyek 02 - AI Material Verification Intelligence (MatVerify)
- `clustify.png` : Proyek 03 - Customer Segmentation for Online Retail
- `website_desa.png` : Proyek 04 - Desa Gongseng Village Digital Portal

> **Tips:** Jika ingin mengganti foto proyek, Anda cukup menimpa file dengan nama yang sama, atau jika menggunakan nama baru, perbarui jalurnya di file `data/projects.js` dan `lib/projects.js`.

---

## 📁 2. `images/organizations/` (Pengalaman Organisasi / Leadership)
Folder untuk foto kegiatan kepemimpinan dan organisasi di bagian **Organization Experience**.
- `posf.webp` : POSF 2025 (Chief Executive)
- `spirit.jpg` : SPIRIT 2025 (Vice Chief Executive)
- `bem_fmipa.jpg` : BEM FMIPA IPB (Staff Member)

> **Tips:** Foto akan otomatis berubah sesuai organisasi yang dipilih atau di-hover pada tampilan portofolio.

---

## 📁 3. `images/experience/` (Pelatihan & Hackathon / Trainings)
Folder untuk foto kegiatan pelatihan, workshop, bootcamp, atau kompetisi hackathon di bagian **Trainings & Hackathons**.
- `dicoding.jpg` : Kegiatan Asah by Dicoding Training

> **Tips:** Anda dapat menambahkan foto hackathon atau pelatihan lainnya di sini (misal `microsoft_hackathon.jpg`, `google_competition.jpg`).

---

## 📁 4. Folder Pendukung Lainnya
- `images/about/` : Foto profil (`profile.png`) dan badge verifikasi (`badge.png`).
- `images/logos/` : Logo-logo teknologi & tools (Python, TensorFlow, Scikit-Learn, MySQL, dll).
- `images/workspace/` : Logo aplikasi produktivitas (Google Workspace, Notion, Meta, Canva, CapCut).
- `images/gif/` : Animasi GIF interaktif untuk kartu keahlian.
